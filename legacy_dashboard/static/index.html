1. Endpoint Tạo Ảnh & Chat Chuẩn OpenAI

POST http://127.0.0.1:8000/v1/images/generations
POST http://127.0.0.1:8000/v1/chat/completions

2. Mẫu gọi bằng Python (kèm Bearer API Key)

import requests

url = "http://127.0.0.1:8000/v1/images/generations"
headers = {
    "Authorization": "Bearer YOUR_GROK_API_KEY",
    "Content-Type": "application/json"
}
payload = {
    "model": "grok-imagine-image",
    "prompt": "Một chú mèo phi hành gia mặc áo giáp neon đứng trên sao hỏa",
    "size": "1024x1024"
}

response = requests.post(url, json=payload, headers=headers)
data = response.json()
print("Link ảnh tạo được:", data["data"][0]["url"])

3. Mẫu gọi bằng cURL (Terminal / Postman)

curl -X POST http://127.0.0.1:8000/v1/images/generations \
  -H "Authorization: Bearer YOUR_GROK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "grok-imagine-image",
    "prompt": "A cyber samurai warrior in futuristic Tokyo, 8k resolution"
  }'
